Lari Kalkun (Turkey Run) is a 2D canvas turkey escape game set on a farm at dusk. You are the turkey running from the farmer before Thanksgiving dinner: switch between three lanes, jump fences, hay bales and the glowing oven, slide under the farmer's nets, dodge the swinging carving knife, and collect corn, feathers for a speed boost, and rare pumpkins for an extra life. The farmer closes in whenever you get hit or dawdle, so keep the gap open and reach the forest 3000 metres away to escape. Three lives, rising speed and denser hazards across the farmyard, the open fields and the forest edge, with WebAudio synth sounds and a best score that sticks around.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Arrow keys or A/D switch lanes, Up/W/Space jumps, Down/S slides, P pauses, R restarts, M mutes. The four screenshots in screenshots/ are real renders of the game's own deterministic ?shot= scenes. All art is drawn in code and all sound is synthesised, so the game runs fully offline from its own files.
